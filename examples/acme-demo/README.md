# Acme Lend (synthetic)

A made-up consumer lending app for India and the EU, written to be audited by Vigil. It has no real data and does not run. The issues planted in it are listed in [`../acme-demo.expected.json`](../acme-demo.expected.json).

The identifiers in `tests/fixtures/users.json` are synthetic: a UIDAI test Aadhaar number, a placeholder phone number and a format-example PAN. The password in `config/settings.py` is not a real credential.

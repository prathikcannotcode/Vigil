# Incident response

1. The on-call engineer opens an incident channel and names an incident commander.
2. The commander assigns a severity from [severity-matrix.md](severity-matrix.md) and records the time in the incident document.
3. Contain: revoke credentials, isolate hosts, preserve logs.
4. For reportable cyber incidents, Security files with CERT-In within 6 hours of noticing.
5. Take the actions listed for the assigned severity.
6. Write a postmortem within 10 working days.
